# Changelog

## Unreleased

- Choose your AI: Claude (default), OpenAI, Gemini, Ollama (local and free) or any OpenAI-compatible server
- Custom characters: a folder of pictures (idle, listening, thinking, done, error, blink, talking) becomes your
  corner buddy, with the same animations as the built-in animals. `heymac --new-character` and `--characters`
- Clear messages when a key is missing, Ollama isn't running or a model doesn't exist

## 0.1.0 (first public release)

- Local speech recognition with Whisper large-v3-turbo, "hey jarvis" wake word and ⌥Space hotkey
- Instant commands without AI: open/quit/hide apps, lock, sleep, volume, media, time and battery
- Claude Haiku for everything else, limited to a fixed set of safe tools
- File search by name or by description ("the instructions for my hw2")
- Send prompts and real file attachments to ChatGPT, Claude, Gemini and Perplexity in Chrome
- Text or AirDrop things to yourself; write, append to and read Apple Notes
- Aesthetic presets: wallpaper, dark mode, Spotify playlist, editor theme, Dock, accent color, Shortcuts, with undo
- Floating corner companion: a lily or one of seven animals (cat, bunny, frog, bear, fox, otter, owl)
- Config reloads automatically when you save it
